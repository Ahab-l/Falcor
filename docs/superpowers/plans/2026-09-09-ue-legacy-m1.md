## 文件与接口

- `Source/RenderPasses/UELegacy/CMakeLists.txt`、`UELegacyConfig.cpp/.h`、`UELegacyPasses.cpp/.h`：插件、runtime metadata、Scene adapter、真实 draw、四个实际 Pass。
- `Source/RenderPasses/UELegacy/UELegacyMaterial.slangh`：原始 UE 属性与参数，程序逻辑不接触 MRT。
- `Source/RenderPasses/UELegacy/UELegacyRaster.3d.slang`：mesh VS、PrePass、BasePass；`UELegacyDecode.cs.slang`：使用相同 Codec 解码及深度重建。
- `Source/RenderPasses/UELegacy/Schemas/DefaultLit.json`、`Codecs/`、`Generated/<generation>/GBuffer.slangh`：由 `scripts/ue_legacy/generate_schema.py` 生成字段存储/分派和包含 Codec 的不可变快照。C++ 读取 runtime metadata，不维护固定五 MRT 表。
- `scripts/ue_legacy/reference_scene.json`：显式参数基线；`m1_smoke.py` 在 build 目录生成参数变体，以独立 CPU oracle 校验 raw packing、深度与 emissive；`schema_smoke.py` 验证 Schema 迁移和事务。

## 第一条路径的资源与数学

- Init 输出五个精确格式 MRT、D32S8 和独立 R32Float `depthCopy`，全帧仅初始化一次。
- PrePass 使用真实 mesh draw，反向无限远投影、GreaterEqual、写 D32S8，同时写 `depthCopy=SV_Position.z`。副本仅供 shader 读取；不冒充原生 depth-plane SRV。
- BasePass 输入输出共享五 MRT 与 D32S8，GreaterEqual、不写深度；按模型 codec 写 target0–3，D 无有效字段；模板 ref=0x86/mask=0xF6。
- View 矩阵来自 Scene camera，但本插件使用自己的无限远 reversed-Z 投影，不改变 stock Camera 持久投影。near 单位米；jitter=0；编码 normal 转回 UE 轴 `(-Falcor.z,Falcor.x,Falcor.y)`，调试重建位置使用 Falcor 米。
- 材质实例读取原始线性 BaseColor、Metallic、Specular、Roughness、Emissive、AO；常量程序多个实例共用。emissive×显式 PreExposure 写 SceneColor，GBuffer 不乘曝光。
- Decode 分开显示 UE normal/basecolor/material/model/depth/位置。C RGB 使用硬件 sRGB SRV，alpha 线性。当前只接受 DefaultLit，不支持输入显式报错。

## 验证与边界

实际 GPU 对照独立 CPU ray/triangle：非边界位置误差 <=0.3mm；normal UNORM10 量化误差 <=2/1023，RGBA16F emissive 为半精度舍入，B 字节/模型精确，C sRGB 编码 <=1 byte 且 alpha 精确。深度副本通过独立重建与 DSV occlusion 正/反对照校验。

M0 的 typed allocation 和不可用的 readonly-depth/stencil-write native DSV 差异继续披露。第一条路径不在绑定 DSV 时读取它，也不因此延后真实 Mesh Pass 的实现。完整 native fidelity 和 UE 新配对截帧仍是独立未关闭项。


## 首轮实测修正

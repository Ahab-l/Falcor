# DefaultLit Mesh 几何专项验收

仍处于已批准的 DefaultLit 闭环阶段；不改变 Schema/Codec 职责或主实施顺序。

1. 建立独立解析平面场景：同一 Scene 同时包含真正的 16/32 位 Mesh、多个实例、正背面、负行列式和非均匀缩放。32 位 Mesh 必须实际引用超过 65,536 个唯一顶点。
2. GPU 结果与解析矩形覆盖、反向深度、世界位置、逆转置法线、双面背面翻转和材质码值比较。检查每个 pass 的真实 draw diagnostics，不能只证明提交过 draw。
3. 对完整原始输出比较重复帧、拆分 BasePass 和全 32 位加载；剔除覆盖与法线必须由独立解析 oracle 判断。
4. 失败先定位原因。仅有测试缺陷就修测试；生产路径问题须有失败证据和最小修复。
5. 保存运行结果、构建身份及报告，更新主进度。该专项不代表整个 DefaultLit 或最终画面一致。

剩余独立项：RDC 材质/法线量化差异、stencil-plane 原始比较、外部 Scene/纹理完整身份。

实施记录：已完成步骤 1–5 的实现和 GPU 运行。限定审查指出初版高位索引仅控制亚像素三角形、拆分节点选择集缺断言；均已补齐并重新通过解析 oracle。报告与结果见 `docs/research/ue-legacy-mesh-acceptance.md`。地板源码分组修正经过 RDC 重渲染/raw 比较，结果 hash 不变，剩余项继续开放。

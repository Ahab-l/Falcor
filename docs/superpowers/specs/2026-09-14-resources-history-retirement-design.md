# Native Asset / History and retirement of legacy UE callers

The user approved retiring old UE callers while retaining useful algorithms/reference data, and migrating Asset and History capabilities to the native framework. This records the concrete execution of the preceding agreed recommendation, not a request to preserve every legacy script or reimplement UE effects.

## Asset
Keep the existing thin GPU resource producer, but accept ordinary `assets` Properties only. Reuse Texture::createFromFile and Device buffer creation. Preserve byte/format/size/mip/Cube/array validation and private source copies restored into graph outputs each execution. Source files load once per pass instance; recreate/updatePass to reload. No old Config, Schema, Scene, snapshot membership or per-frame file hashing. Formats/kinds remain the currently supported texture and raw-buffer scope, not a new asset manager.

## History
Keep graph-composable read/write nodes sharing pair storage scoped to their graph, paired by explicit key and identical resource declarations. `make_graph` binds and validates only graphs containing history nodes; direct native graphs have an explicit bind helper. Reader precedes writer via graph dependency. Writer status must remain marked to avoid pruning. Ordinary graph execution advances history once whenever its writer executes; no separate frame scheduler, epoch, clock capture, wait/readback or whole-graph transaction. An explicit reset clears validity and sequence; resize, new Scene assignment and rebinding invalidate history. Shader inputs report valid/sequence status; effect-specific delta time is an explicit uniform/resource, not inferred from UE frame contracts. A writer publishes after recording its own complete GPU copies; failures downstream do not roll back already published history. There is no automatic camera-cut detection or wall-clock pause deduplication.

## Retirement
Inventory callers by source dependencies, then archive original bytes and a path/hash/reason manifest before removing old runnable entrypoints and old-ABI-only tests from the active tree. Preserve useful Shader/CPU algorithm implementations, independent tests, source provenance, inputs and historical evidence; archive retained legacy wrappers as research material if needed. Native GBuffer/Schema, observer/UI source, resource/core regression capabilities must not be deleted just because they share an old helper: extract or replace narrow helpers first. Do not migrate targetmap/old UE rendering effects as part of this request. New runtime must not quietly re-enable legacy APIs to keep retired tests green. Retained unbuilt research sources are not supported runtime entrypoints.

## Validation / boundaries
Use the existing Falcor-m0 worktree and keep unrelated uncommitted work. Original byte backup: build/resource-history-migration. Test native Asset known DDS/raw bytes, input destruction restoration, mismatches and explicit reload. Test native History known sequences, multiple isolated graphs/keys, reset/resize/rebind, normal graph execution and pair/order/format validation; verify no legacy module import and no synchronous waits in its execution path. Re-run native described/mesh/Schema/observer and resource/subresource regressions. Retired tests are accounted for explicitly, not silently skipped. Preserve references and verify removal/incoming-import integrity. Build pinned CMake 3.24.1 Release Mogwai; headless GPU only. Independent review, Chinese usage/Todo and exact verification index; no commit/merge, V5 work, whole-graph rollback, UE effect translation or final RDC work.
